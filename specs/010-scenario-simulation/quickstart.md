# Quickstart: Scenario Simulation

1. Generate a thin-slice dataset from the Demo page.
2. Run a base optimization and copy its run ID.
3. Open `/scenarios`, enter the generation ID, and apply the flagship pack.
4. Run a scenario against the base run and review the grouped objective/unserved bars.

Results are simulation outputs. Only `Feasible` runs are marked as recommendations; failed or infeasible runs retain an explicit non-recommendation label.
